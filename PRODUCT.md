# Product

## Register

product

## Users

The primary user runs Fedora with i3/X11 on a laptop, works in both Russian and English keyboard layouts, and needs a reproducible desktop configuration that remains understandable without memorizing hidden state.

## Product Purpose

Provide a Fedora-ready i3 environment for daily work: predictable tiling, visible system controls, reliable suspend and lock behavior, clipboard and speech-to-text integration, and an installer that can reproduce the setup from GitHub.

## Brand Personality

Calm, technical, and explicit. The interface should feel dependable rather than decorative and should explain consequential actions in plain language.

## Anti-references

Avoid unexplained icon-only controls, invisible keyboard modes, ornamental lock screens with no instructions, Wayland-only helpers in the X11 session, and hidden defaults that change between logins.

## Design Principles

- Make system state visible before requiring action.
- Prefer familiar controls and direct labels over clever interaction.
- Keep every shortcut independent of the active RU/EN layout.
- Preserve user data and session continuity across reboot and reinstall.
- Use native Fedora, i3, systemd, and X11 behavior before adding dependencies.

## Accessibility & Inclusion

Maintain readable contrast, visible keyboard focus, mouse and keyboard access, plain-language Russian labels where guidance is needed, physical-key shortcuts that work under RU and EN layouts, and minimal nonessential motion.
